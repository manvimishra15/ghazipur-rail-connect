# ZRTI Ghazipur Frontend

React frontend for the official website of **Zonal Railway Training Institute, Ghazipur**.

## Available Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run preview` previews the production build locally.
- `npm run test` runs the Vitest test suite.

## Current Structure

- Public pages for Home, About, Training Information, Knowledge Centre, Trainees Information, E-Magazine, Facilities and Contact.
- Admin login and a simplified dashboard prepared for future backend integration.
- Modular mock content designed to be replaced later by endpoints such as `/api/news`, `/api/courses` and `/api/login`.
